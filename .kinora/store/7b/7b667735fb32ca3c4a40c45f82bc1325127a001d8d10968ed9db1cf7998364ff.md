# Spec — the human console is a projection of the job-world

**Contract.** The human console renders the *same* job objects the agent operates
on — running / awaiting-approval / done, tail-able, across all nodes. There is one
source of truth (the job substrate); the console is a view over it, never a
parallel state model.

**Chosen.** A single substrate that both the agent and the console read. The
console *projects* job state; it does not store or simulate it.

**Rejected.** A human UI with its own state model. Two sources of truth drift, and
the human ends up watching a *simulation* of the agent rather than the agent
itself.

**Escape hatch.** The console may hold ephemeral view state (scroll position,
filters, local selection) — anything that is not authoritative job state and never
feeds back as truth.
