# Spec — read-only agent introspection minimizes human round-trips

**Contract.** The agent has enough **read-only** power to get a command right
*before* spending a human approval: **preflight(argv, cwd)** that runs and queues
nothing yet resolves the disposition a real run would get (allow / needs-approval /
deny), whether `argv[0]` resolves on the daemon PATH and to what absolute path, the
effective PATH, and the confined resolved cwd (or the confinement error);
**read-rules** (list the current allow/deny overlay); **read-audit** (past runs);
**self-describing outcomes** (a completed run echoes the absolute symlink-resolved
cwd it ran in and the verdict it ran under — the *same* verdict written to the
audit); **legible spawn failures** (name the binary and the PATH searched); and
**bounded execution** (an execution deadline plus a client-side RPC timeout).

**Chosen.** Give the agent inspection so it self-corrects; each capability is a
human round-trip removed. Preflight is a distinct always-read-only method.

**Rejected.** A `--dry-run` flag on the run call — a dry run must *never* be able to
enter the pending queue or execute; and a separate "where did that run" round-trip
— the provenance is free at run time.

**Escape hatch.** If the agent still cannot resolve a command read-only, it falls
through to the normal approval gate; introspection reduces prompts, it does not
replace the gate.
