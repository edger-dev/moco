# Spec — every attempt is durable history, denials included

**Contract.** Every attempt — **including every denied one** — is written
append-only and flows into the same encrypted, never-delete backup pipeline as the
rest of the system's records, readable back and browsable in the console like any
other historical object. Output beyond a cap is truncated inline with a pointer to
the archived full record.

**Chosen.** Audit as durable, append-only history on the never-delete backup — one
pipeline shared with all other records. The audited verdict is the same value
returned to the caller (§3), so there is one source of truth for "under what
authority did this run".

**Rejected.** Dropping denials or unbounded inline output. A denial is exactly the
event worth keeping; unbounded output would bloat the record instead of pointing at
the archive.

**Escape hatch.** A searchable audit index, push notifications, and
streaming-while-running for the *human* are deliberate v1 non-goals — the substrate
makes them additive later without changing the record.
