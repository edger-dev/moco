# Spec — worktree and host are start-time gates with informative refusals

**Contract.** Two declared admission dimensions, the same shape on different axes.
Both are evaluated **at start**, never at parse, and a refusal is an outcome that
**names the gate and the reason** — never a config error and never a silent failure.

**`worktree = "each" | "main-only"`** — a policy *within* workspace scope
(kino://0d85bf8a00d18597ab8446e3ff9a95c7e1a25e7e0866cf33f03f4509c2f57c2f), orthogonal
to Workspace-vs-System.

- `each` (default) — every worktree of the repo runs its own instance, each with its
  own `auto` port.
- `main-only` — only the main working tree runs it. Detection reuses an existing
  boundary: the main tree's `.git` is a **directory**, a linked worktree's is a
  **file**.
- **A fixed integer port defaults `worktree` to `main-only`**, since two worktrees
  cannot bind one port, unless set explicitly.

**`hosts = [...]`** — an allow-list of **node names**, so one checked-in manifest,
shared across machines, can pin a machine-specific job to one box.

- **Matched against the node identity injected into the engine**, never the OS
  `hostname`.
- Absent = runs anywhere. Both fields compose freely.

**Enforced in the engine's `start`**, so every entry point — boot, session-ensure,
explicit — is covered by one gate. `ensure` skips a refused job silently; an
explicit start reports which gate refused and why. These are **policy** gates and sit
alongside, never in place of, the trust gate of
kino://a457400202f392b8f3cb8c1266e0e7a8b4ca92ed3cff07e1fcd54e1952442226.

**Chosen.** Start-time gates with informative refusals, enforced at one chokepoint.
The refusal-shape is the reusable part: every axis added later inherits "one gate,
one message, one enforcement point".

**Rejected.** Modelling `main-only` as a System-scoped daemon — these are repo jobs;
cwd matters and they belong in the repo's manifest. Also rejected: running everywhere
and letting the OS reject the second bind, which trades a clear policy for noisy racy
failures. Also rejected: matching the OS `hostname`, which makes the engine call out
to the OS and diverge from the mesh's canonical node identity that is already plumbed
in. Also rejected: a per-host manifest (defeats the point of one shared file) and a
single `host` string (a list is a strict superset at no cost).

**Escape hatch.** Both fields absent is the permissive default: the job runs in every
worktree on every node.
