# Spec — an ad-hoc start carries the job's environment and its human view

**Contract.** A `start` request (the ad-hoc path, argv and cwd named by the
caller) may also carry:

- **`env`** — variables set for the job on top of the node's own
  environment, in order, a later name overriding an earlier one; the port
  variable a declaration allocates is still the node's to set;
- **`human_view`** — `Logs` (the default) or `Terminal`, with exactly the
  meaning it has in a declaration: a terminal job draws through a pty owned by
  the PTY holder, and its screen is readable over the wire.

Both are optional: a request without them starts the job as before. The reply
says what was applied (how many variables, which view), so a caller can tell
a node that honoured them from an older one that ignored them.

A variable name must be non-empty with no `=` or NUL, a value hold no NUL;
anything else is refused. A **governed** node refuses an environment
outright: its rule-set matches argv alone, and variables (`PATH`,
`LD_PRELOAD`, …) could change what an allowed argv runs.

**Chosen.** Give the ad-hoc path what a launcher needs. A kudo node starts an
agent worker — an interactive CLI bound to a context by environment variables
(the context, the lease, the store) — in a pane a person can take over. With
neither field, the only way through was a manifest entry per worker, which a
worker launched on demand cannot have, or `sh -c` with the variables spliced
into a command line, which is exactly the shell string argv-not-shell exists
to avoid.

**Rejected.** Environment through `sh -c` (a shell string, quoting hazards,
secrets in argv). A per-worker manifest entry (workers are started on demand,
by the caller, not declared). Inheriting the caller's environment (the caller
is on another machine; nothing of its environment belongs on this one).

**Escape hatch.** A declaration gains the same `env` field when one needs it;
the spawn path is shared, so the field means the same thing in both places.
Governance can admit environments once the rule-set can match on them (names,
or names and values), and the approval prompt shows them.
