# Spec — the byte substrate is one streaming `Place` trait, in moco

**Contract.** Content-addressed bytes live behind one trait, `Place`, in
framework-free moco crates (no cell framework, no facet). A place offers:

- **put-once** of a stream whose BLAKE3 hash and size the caller declares up
  front; an object already there is never overwritten;
- **get**, a stream with an optional byte range;
- **exists** and **list** (by prefix, one level);
- **verify** and **inventory**, with default implementations (read and hash;
  walk and hash) a place overrides when it can do better — a served node
  verifies its own disk and ships only the result.

A place states three capabilities: online, writable, cold (a read costs money
or hours). Nothing else varies between places. The caller hashes before it
puts, so the final key is known before any byte moves; a place that can
re-hash on arrival (a file system, a served node) does, and refuses a
mismatch; an object store's copy is checked by the next verify.

**Why.** Kinora's ledger and kura's media need the same five things at
different sizes. One streaming trait carries both — a small read is a short
stream — and maps one-to-one onto the hub connector that serves places
remotely. Hashing first avoids an upload under a temporary name and a rename
an object store cannot do cheaply; imports start from local files, where the
second read is cheap.

**Rejected.** A core trait plus media and verify extensions (the connector
flattens them anyway; trait objects would need downcasting). One wide trait
with refusal flags (every caller handles "not offered"). Hashing while
streaming (one read, but a rename on S3). Crates in kinora's repo first, moved
later (two moves; the layering of RFC-0005 false meanwhile). Keeping kinora's
mirror as a full-copy sync with no trait (no partial copies, no offline
places).

**Escape hatch.** A capability may be added when a place genuinely differs in
a way callers must plan around (pack files may need one); the trait's
operations stay five plus the two defaults.
