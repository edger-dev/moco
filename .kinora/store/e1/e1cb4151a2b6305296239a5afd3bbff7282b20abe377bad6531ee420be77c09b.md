# Spec — four approval verdicts; "always" writes an exact-argv rule

**Contract.** When a proposal matches no rule, the human is offered four verdicts:
**allow once** (run this instance, write nothing), **allow always** (append an
allow rule matching this **exact argv on this node**, then run), **deny once**
(reject, write nothing), **deny always** (append a deny rule for the exact argv,
then reject). **Deny beats allow** on a match. The "always" verdicts are the only
way the standing whitelist grows.

**Chosen.** Exact-argv scope for every standing grant, modeled on a coding agent's
own permission prompts. Each standing allow is a thing a human chose verbatim,
keeping the audit legible.

**Rejected.** Broad "program-only" or "prefix" auto-scoping on approval — allowing
one invocation of a tool must not permit every invocation of it.

**Escape hatch.** Recurring *parameterized* commands are handled by a committed seed
recipe (§2.4), not by widening a single approval click.
