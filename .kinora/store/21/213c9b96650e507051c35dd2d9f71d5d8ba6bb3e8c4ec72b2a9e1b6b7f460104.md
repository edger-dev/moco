# Spec — an ad-hoc start without a cwd runs in the node's allowed root

**Contract.** An ad-hoc start that gives no cwd runs in the target node's allowed
root. The caller's own directory is the default only when the caller is on the
target node itself (the same machine, so the path exists there).

**Why.** The job tools sent the caller's own directory when none was given. On a
remote node that path does not exist and the allowed root refuses it, so the
first remote start failed with an error that did not say why.

**Rejected.** Refusing a missing cwd with a better message: correct, but every
remote start would then need a path the caller has no way to look up.

**Escape hatch.** An explicit cwd is always used as given, and still has to be
inside the allowed root.
