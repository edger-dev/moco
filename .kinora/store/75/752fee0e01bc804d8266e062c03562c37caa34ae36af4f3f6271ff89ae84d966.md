# Task — a launchable, typable terminal job

For kudo's console (phase 4 of `kudo:c0d2c76488b561c631bc29b995424ef3e8b9c3d3fdbad5a2db4896bf72b48c0d`):
a node starts an agent worker in a real pane through the hub, and a person
types into it from the console.

**Specs:** kino://e1ac0834cf78d3b21ccb294986f3cc2dd2b4d078f7b8390a779a8cc558126841 — an ad-hoc start carries the job's environment and
its human view; kino://4ef2467e0ecf835f0f47575d78eefbb89fc13f4b15c68d4ff992c1942b985b9e — a terminal job accepts input.

**Plan:** kino://d6ffd353f6a09cc95009abbe01059bfbd3a0f2c07e0879fa6057ab499aec416d

## Done-when

- `start` takes `env` and `human_view`; a terminal job started that way is
  read back through `screen`.
- `input` writes bytes to a terminal job's pty, through the holder's FIFO
  when there is one, and is refused for a job that is not a terminal.
